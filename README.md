# 별누리

오늘 밤 내 머리 위의 진짜 하늘에서 출발해 별과 행성 사이를 날아다니는 3D 우주 웹사이트입니다.
실제 별 5천 개와 태양계를 탐험하고, 황도 12궁 성좌판과 별자리 운세도 함께 즐길 수 있습니다.

## 기능

- **회전 성좌판 (운세 고르기)**: 운세 방 맨 위의 원판을 드래그해 돌리면 상단 지침이 가리키는 날짜의 별자리와 그 성격, 신화가 나오고, 아래 운세가 그 별자리로 바뀝니다. 별자리를 클릭하면 그 별자리로 돌아가고, 키보드는 ←/→(이전·다음 별자리)와 Home(오늘)을 지원합니다.
- **오늘의 운세**: 그날 실제 달이 있는 별자리와 달의 위상을 계산해, 내 별자리와 이루는 각도(합, 60°, 90°, 120°, 180°)에 따라 내용과 점수가 달라집니다.
  총운, 애정운, 금전운, 일과 공부, 건강운, 키워드, 시간대별 흐름과 앞뒤 사흘 흐름 차트, 오늘의 미션과 피할 것, 행운 정보를 보여 줍니다.
- **전문 운세 (탭: 오늘 · 이번 주 · 이번 달 · 1년 · 내 차트 · 궁합)**: 태양·달·수성~명왕성의 실제 황경으로 계산합니다 (`js/ephemeris.js`).
  - 오늘: 10천체의 별자리·도수·역행과 내 별자리 기준 하우스, 달의 별자리 이동 시각과 보이드 오브 코스, 다음 새달·보름(식 포함), 출생 차트와 오늘 하늘의 트랜짓을 힘·긴장·주의로 나눈 개인 운세와 Do/Don't.
  - 이번 주: 7일 흐름, 달이 지나는 하우스, 행성끼리 정확한 각도, 나에게 정확히 닿는 날.
  - 이번 달: 하늘 달력(새달·보름·식·역행·별자리 이동), 좋은 날·조심할 날.
  - 1년: 목성·토성이 지나는 하우스와 이동 날짜, 일식·월식, 역행 기간.
  - 내 차트: 원형 차트, 천체별 별자리·도수·홀사인 하우스, 원소·양식 균형, 주요 각도와 해설. 태양궁·달궁·상승궁 중 운세 기준을 고를 수 있습니다.
  - 궁합: 두 출생 차트의 시너스트리(끌림·대화·정서·책임·성장).
- **별누리만의 연결**: 모든 사건에 '하늘 보기'가 붙어 그 순간의 실제 하늘을 3D로 엽니다 (`index.html?t=시각&p=천체`). 태어난 순간의 밤하늘, 실제 하늘에서 태양이 있던 별자리(세차, 뱀주인자리), 내가 태어날 무렵 빛이 출발한 '생일 별'을 보여 줍니다.
- **오늘의 별 카드**: 엎어 둔 카드 세 장 중 하나를 뒤집으면 실제 밝은 별의 이야기가 담긴 메시지가 나옵니다. 하루 한 번.
- **별자리 궁합**: 두 사람의 생일로 태양, 달, 원소 궁합 점수와 해설을 보여 줍니다.
- 운세는 `날짜 + 별자리`로 시드를 만든 난수로 정하기 때문에, 같은 날 같은 별자리는 언제 열어도 결과가 같습니다.
- **밤하늘 (첫 화면 index.html, 3D)**: 날짜, 시각, 장소(또는 내 위치)로 맨눈 한계(6등성)까지 실제 별 5,044개와 88개 별자리의 위치를 계산합니다.
  - 올려다보기: 지면에 서서 끌어서 둘러보는 3D 하늘. 실제 윤곽 데이터로 그린 은하수, 등급에 따른 밝기(1등급 = 2.512배), 대기 감광과 반짝임, 달빛에 묻히는 별, 노을을 표현합니다.
  - 별 정보: 이름 있는 별 493개를 누르면 한국어 이름과 옛 이름, 밝기 순위, 거리, 빛이 출발한 해, 색과 온도, 이야기가 나옵니다. 별이나 별자리 이름으로 찾을 수도 있습니다.
  - 행성: NASA JPL 궤도 요소로 관측 날짜의 수성~해왕성 위치와 밝기를 계산해 하늘에 표시합니다. 누르면 거리, 빛이 오는 시간, 밝기 정보가 나옵니다.
  - 입체 우주: 별을 실제 거리(광년)로 옮겨 별자리 주위를 돌아봅니다. 가까이 가면 별이 밝아지고(겉보기 등급을 카메라 거리로 다시 계산), 태양 쪽으로 다가가면 행성 궤도가 있는 태양계가 나타납니다. 행성은 실제 표면 지도로 그렸고(지구는 관측 시각의 실제 자전 각도, 밤쪽 도시 불빛, 구름, 대기), 행성끼리 크기 비율은 실제와 같습니다. 다만 전체를 보기 좋게 키웠고 태양은 작게 그렸습니다. 끌어서 회전, 오른쪽 끌기로 이동, 휠로 가리키는 곳에 다가가기, 별 두 번 눌러 그 별 주위 돌기, 화면 버튼과 키보드를 지원합니다.
  - 전천 지도: 머리 위 하늘 전체를 원 하나에 펼친 2D 지도.
  - 발견하기: 선과 이름을 숨긴 채 별을 눌러 별자리를 찾고, 찾은 별자리는 도감(브라우저 저장소)에 남습니다.
  - "내 위치에서 지금 하늘 보기"를 누르면 브라우저 위치 권한으로 현재 위치의 하늘과 보이는 별자리를 보여 줍니다. 위치는 브라우저 밖으로 보내지 않습니다.

## 실행

빌드 과정이 없는 정적 사이트입니다. 3D 밤하늘은 ES 모듈과 위치 권한을 쓰기 때문에 로컬 서버(또는 GitHub Pages 같은 https 주소)로 여세요.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 배포 (GitHub Pages)

배포 전에 `python3 -I tools/bump_version.py`로 CSS·JS 주소의 `?v=` 값을 바꿉니다. GitHub Pages는 파일을 브라우저에 10분쯤 캐시하게 해서, 새 HTML과 옛 JS가 섞이면 페이지가 멈출 수 있기 때문입니다.

저장소의 Settings → Pages에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)`로 지정하면
`https://hyuny0219.github.io/horoscope/` 주소로 공개됩니다.

## 구조

```
index.html      1 밤하늘 전시실 (첫 화면)
css/style.css
js/data.js      12궁 별 좌표, 설명, 운세 문장
js/wheel.js     회전 성좌판 캔버스
js/astrology.js 별 지도(태양궁, 달궁, 상승궁), 각도, 궁합, 해설 문장
js/fortune.js   날짜와 실제 하늘 기반 운세 생성
js/ephemeris.js 점성술 천체력 (행성 황경, 역행, 상승점, 보이드, 새달·보름·식, 트랜짓, 시너스트리)
js/astro-text.js 천체 × 각도 × 하우스 해설 문장
js/pro.js       전문 운세 탭 화면
js/charts.js    운세 차트 (시간대, 7일, 궁합)
js/main.js      화면 연결
zodiac.html     2 운세 전시실 (성좌판으로 별자리를 고른다)
js/sky-data.js  별 목록과 별자리 선 (tools/build_sky_data.py로 생성)
js/astro.js     천문 계산 (항성시, 지평좌표, 해와 달, 행성)
js/sky3d.js     3D 하늘 (Three.js, CDN에서 불러옴)
js/sky-view.js  2D 전천 지도
js/milkyway.js  은하수 점 (2D 지도, 배경)
js/milkyway-data.js, assets/milkyway.png  실제 은하수 윤곽으로 만든 점과 전천 이미지 (tools/build_milkyway.py로 생성)
js/backdrop.js  페이지 배경의 실제 밤하늘
```

## 데이터 출처

- 별 위치, 별 이름, 별자리 선, 은하수 윤곽: [d3-celestial](https://github.com/ofrohn/d3-celestial) (BSD-3-Clause, `tools/LICENSE-d3-celestial.txt`)
- 행성 궤도 요소: NASA JPL "Keplerian Elements for Approximate Positions of the Major Planets"
- 별까지의 거리: [HYG Database](https://github.com/astronexus/HYG-Database) (CC BY-SA 4.0)
- 출생지 도시와 시간대: [city-timezones](https://github.com/kevinroberts/city-timezones) (MIT, Natural Earth 자료 기반), `js/places-data.js` (`tools/build_places.js`로 생성). 태어난 해의 시차(서머타임, 옛 표준시)는 브라우저 시간대 정보로 계산합니다.
- 행성·태양·달 표면 지도: [Solar System Scope](https://www.solarsystemscope.com/textures/) (CC BY 4.0, NASA 자료 기반), `assets/planets/`

데이터를 다시 만들려면 위 원본 파일을 한 폴더에 받은 뒤 `python3 -I tools/build_sky_data.py <폴더> js/sky-data.js`를 실행합니다.
